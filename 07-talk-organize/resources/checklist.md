# 交付前逐项核对（学术汇报内容组织）

每项写进 compliance_checks：`{"check": ..., "result": "PASS|FAIL|WARN|未核对", "basis": "实测依据"}`。

## A. 目标与听众（talk_plan.md）
- [ ] 目标是一句可检查的话：听众 + 时长 + 要认可/理解的内容 + 依据的证据
- [ ] 听众画像写了先验知识、关注点、最可能的质疑；背景页数与之相符
- [ ] 场合侧重点正确（组会=方法与进度；开题/中期=意义、可行性、风险；答辩=创新与边界；评审=结论强度；会议=单一核心发现）
- [ ] 没给听众/时长时，假设写明并列入 uncertainty

## B. 取舍与叙事
- [ ] 取舍表覆盖论文全部图表和主要结论，每条有去向（上页/备注/备用页/不讲）和理由
- [ ] 叙事不是论文目录顺序；相邻页有过渡句（在备注里）
- [ ] 每页唯一主张；标题是主张句
- [ ] 每页秒数合计 = 时长 ±10%；页数符合工作单（checker `--slides N`）

## C. 证据
- [ ] content_map 每页有 locator（Fig/Table/Sec/页码）和原句短引
- [ ] 每条结论标了证据强度；弱证据没做成结果页标题；措辞强度与证据匹配
- [ ] 数字照抄原文，checker 数字回查无小数 FAIL；自己算的数有算式
- [ ] 他人结果标"[n] 报道"

## D. 问答准备（qa_prep.md）
- [ ] 5–8 个追问，覆盖机制、数据/统计、对照、局限、可推广性
- [ ] 每题有回答要点、原文位置、可翻到的页或备用页
- [ ] 回答口径与页面一致；材料答不了的如实写

## E. 模板与导出
- [ ] checker `--template` PASS（母版/版式/主题未改，页面都用模板版式）
- [ ] 无模板提示文字残留、无占位图；页脚页码沿用模板
- [ ] presentation.pdf 页数 = 幻灯片数；preview PNG 存在；pdffonts 实测写入记录
- [ ] 每页有备注且不复述页面

## F. 结果文件
- [ ] contract 字段齐全；status 一个词；exceptions 分"材料缺失 / 无法判断 / 运行失败"
- [ ] check_result.py PASS
