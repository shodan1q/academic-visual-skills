# 设计说明与内部测试记录

> 内部记录：只用作者自己编写的合成案例，不是平台正式案例；不给、也不推测任何正式分数。

## 1. 为什么是“说明为主 + 两个标准库脚本”
- 上一轮经验：重型流水线在正式环境因依赖、路径、超时得 0 分；说明为主的精简 Skill 稳定。本包只有 SKILL.md 和两个各 ≤ 200 行的标准库脚本，无安装。
- 预算 64 次请求 / 900 秒：流程按 ≤ 30 次调用设计，第 3 次调用内写 result.json 骨架。
- 数据图的典型失败是“画得像但不准”，且肉眼看不出来。所以核心不是更漂亮的模板，而是**从生成文件回读图元并与源数据对账**（`marks`），加上逐条标注规则。

## 2. 规则与题面失败形态的对应
| 失败形态 | 对应规则 / 机制 |
|---|---|
| 数值与源数据对不上 | 数值只从数据文件读（`table` 带行列号），派生量复算；`marks` 回读 SVG 几何并线性拟合，残差 > 2 % FAIL |
| 说不清每根柱来自哪一行哪一列 | datamap.md + data_trace 内嵌表（文件!行列、复算方式） |
| 图例与系列错配 | 每个图元 gid 与期望值 id 对应；标注规则 2 |
| 坐标轴量级或单位写错 | 标注规则 1（量 + 单位 + 量级，柱从 0 开始） |
| 误差线含义、显著性标记无出处 | 标注规则 3、4：误差按数据核对，显著性只取自统计输出 |
| 实体名拼错、中文变方框 | 照抄规则；模板自动选已安装的 CJK 字体并打印；check 对“中文无 CJK 字体”FAIL |
| 导出位图、文字转曲 | svg.fonttype none、pdf.fonttype 42；check 对无 `<text>` 或无预览 FAIL |
| 改一处要重画 | STYLE 字典 + 数据驱动脚本，重跑出 v2；`diff` 记录 |
| matplotlib 缺失 | `svgchart` 回退 + `render` |

## 3. 内部合成测试
| 项 | 内容 |
|---|---|
| 案例 | `case03`：合成 IL-6 数据（xlsx，12 只小鼠，sheet 名与任务描述不符）+ 统计输出（误差类型说法与数据矛盾）+ 改中文轴标签的请求；contract 为 properties/required + enum |
| 执行方式 | 作者按 SKILL.md 执行：骨架 → table → datamap → 按模板写 make_chart.py（matplotlib 3.10）→ marks → 记录 → 改 STYLE 出 v2 → diff → check |
| 发现与修正 | ① 柱长和散点位置放在同一次拟合里会全部判 MISMATCH → `marks` 改为按“长度/位置”分组拟合；② 中文轴标签在 Arial 下出现缺字警告 → 模板改为先查已安装字体、把 CJK 字体放第一位；③ matplotlib 每次运行的标记/裁剪 id 是哈希，diff 噪声很大 → diff 过滤哈希 id 并识别 `<g id="text_N">` 里的文字 |
| 结果 | 15 个图元样本 marks PASS（v1、v2）；把一个期望值改错后 FAIL 并定位到该柱；diff 只剩 1 处文字改动；check PASS，status partial（误差类型待确认、sheet 名不符） |
| 回退路径 | 无 matplotlib 时 `svgchart` 生成柱图与折线图，rsvg-convert 渲染，marks 分别 PASS（3 柱、8 个折线顶点） |

## 4. 仍做不到的
- 箱线图、热图的回读需要在脚本里自行实现并写结论。
- 不判断统计方法是否合适；只保证图上的统计标注都有出处。
- 纯文本模型无法从材料中的图片读数，只能依据数据表并如实说明。
