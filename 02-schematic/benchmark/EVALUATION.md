# 设计说明与内部测试记录

> 内部记录：只用作者自己编写的合成案例，不是平台正式案例；不给、也不推测任何正式分数。

## 1. 为什么是“说明为主 + 两个标准库脚本”
- 上一轮经验：重型流水线在正式环境因依赖、路径、超时得 0 分；说明为主的精简 Skill 稳定。本包只有 SKILL.md 和两个各 ≤ 200 行的标准库脚本，无安装。
- 预算 64 次请求 / 900 秒：流程按 ≤ 30 次调用设计，第 3 次调用内写 result.json 骨架。
- 示意图最致命的是结构错（包含画成并列、方向画反）。SKILL.md 把关系类型映射成固定画法，由模型在实体—关系清单里先判定；几何、端点、图例、换行由 `svgfig.py` 生成并告警。

## 2. 规则与题面失败形态的对应
| 失败形态 | 对应规则 / 机制 |
|---|---|
| 抑制画成激活、上下游颠倒 | 关系语法表：activate / inhibit 端点不同；方向 = 因果/时序方向；“被抑制”的写法规则 |
| 包含关系画成并列 | 包含 = 嵌套 panel，不用箭头；并列 = 网格同行同尺寸 |
| 材料中不存在的基因名、浓度、时间、单位 | 每个元素必须带 `src`，缺失告警；check 告警来源映射中找不到的数字 |
| 图例与数据表对不上、颜色数与类别数不一致 | 着色和图例由同一段 python 从数据表生成；清单逐项核对 |
| 只有位图、改标签要重画 | spec + 分层 SVG；`edit` 按 id 改，`diff` 证明其余不变；无 `<text>` 或无预览即 FAIL |
| 分辨率、字体嵌入、线宽不合期刊要求 | `width_mm` 物理尺寸、有效字号公式、render 报告 PDF 字体嵌入、dpi 可设 600 |
| 文字溢出、引导线交叉 | build 告警标签溢出、边穿越节点、via 点落在节点内；check 告警越界与重叠 |

## 3. 内部合成测试
| 项 | 内容 |
|---|---|
| 案例 | `case02`：合成类器官药筛流程（5 行，含“三组并行”“两项检测并行”）+ 3 行处理组表；单栏 85 mm、600 dpi；contract 键为 `deliverables` |
| 执行方式 | 作者只按 SKILL.md 执行：骨架 → 读材料 → 关系清单 → python 由数据表生成 spec → build → render → 演示编辑 → 记录 → check |
| 发现与修正 | 首版画布 680 px 宽，按公式在 85 mm 下最小字号只有约 5 pt；据此改写 SKILL 的期刊尺寸规则（单栏画布 340–420 px）并给 build 增加 `width_mm`；重排为 400 px 后最小有效字号 7.2 pt。演示编辑只改了换行，旧 diff 看不出，改为按 tspan 分行比较后检出 |
| 结果 | build 无告警；PDF 物理宽 85 mm、字体全部嵌入；PNG 600 dpi；diff 只有 1 处改动、41 个 id 保留；check PASS |
| 人工查看 PNG | 三个处理组同行同尺寸并被外框包住（并列 + 分组），流程单向，分叉到两项检测，图例 4 项与图一致 |

## 4. 仍做不到的
- 不自动排版；复杂结构图的美观依赖模型给的坐标。
- CMYK/EPS 依赖外部工具，缺失时只能记为缺口。
- 纯文本模型读不了材料中的草图图片，只能依据文字与表格并如实说明。
